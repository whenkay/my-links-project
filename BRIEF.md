# My Links - Project Brief 
A personal link-in-bio page. Mobile first, simple clean design. I want to send people here from my social profiles. 

## Tech
- Pure HTML, CSS, and JavaScript - no frameworks, no build tool 
- Single index.html file (CSS and JS can be separate files)
- Deploys to Vercel as a static site

## Design
- centered card layout, max-width 480px
- My name as heading, short bio underneath
- Profile photo placeholder (circle, 120 px)
- Light mode by default
- Smooth hover animations on the link buttons
- Google font: Inter
- background color: light blue to gray gradient
